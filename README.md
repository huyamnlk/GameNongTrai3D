# GameNongTrai3D

Unity farm simulation project.

## Open the project

1. Install the Unity Editor version listed in `ProjectSettings/ProjectVersion.txt`.
2. In Unity Hub, choose **Add project from disk** and select this repository folder.
3. Open `Assets/Scenes/Farm.unity` to view the main farm scene.

## Repository contents

- `Assets/`: Unity scenes, scripts, art, audio, and other project assets.
- `Packages/`: Unity package manifest and lock file.
- `ProjectSettings/`: Unity project settings.
- `Android/Android.apk`: available Android build.
- `Docs/`: project and gameplay documentation.

Unity's generated `Library/`, `Logs/`, and local editor settings are excluded; Unity recreates them when the project is opened.
